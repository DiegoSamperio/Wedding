# Material pendiente real

La web ya utiliza directamente el arte final extraído de la invitación: portada, RSVP, timeline, itinerario, dress code, croquis, familia, hospedaje, regalos y cierre. Esos elementos ya no están pendientes.

## Fotografías personales opcionales

La página está visualmente completa con ilustraciones de la invitación. Solo se necesitan fotografías si Daniela y Rodrigo desean reemplazar o complementar ese arte.

- Foto principal para Inicio: confirmar si sustituirá la portada ilustrada actual.
- Galerías de Propuesta y Pedida: integradas y optimizadas para web.
- Foto para Cierre: confirmar si sustituirá la ilustración de Daniela, Rodrigo y Bagheera.

Formato recomendado: JPG o WebP, mínimo 1800 px por el lado largo y sin marcas de agua.

## Tipografía opcional

La invitación utiliza Symphony Pro. La web ya cuenta con una alternativa visual compatible. Si se desea usar la tipografía exacta, se necesita confirmar la licencia web y entregar:

- `public/fonts/symphony-pro/SymphonyPro-Regular.woff2`
